# Category: Discord Bots
# Title: Giveaway Bot Commands and Features
# Last Updated: 2026-08-26T22:37:12.974Z

Apollo and Falcon bots are used to manage giveaways:
- **Apollo**: Announces giveaway start/end, displays winner announcements, handles re-rolls
- **Falcon**: Tracks invite counts, displays invite lists, shows invite statistics (joins, leaves, fake invites, rejoins)
- **InviteLogger**: Provides detailed invite breakdowns including joins, leaves, fake counts, and bonus invites
- Giveaways display: prize, end time, participant count, and winner information
