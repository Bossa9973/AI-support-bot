# Title: How to Redeem a VPS Code and Deploy
# Last Updated: 2026-08-26T22:37:12.961Z

Once you have a VPS code:

1. Redeem the code in your dashboard
2. Deploy the VPS (note: this can only be done after panel maintenance is complete)

After redeeming, you'll be able to access and configure your VPS through the panel.
